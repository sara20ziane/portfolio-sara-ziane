# Portfolio de Sara Ziane

Portfolio responsive présentant deux applications web conçues à partir de besoins réels :

- **Yuna's Shop CRM** — suivi des commandes, clientes, arrivages, pesée et finances.
- **ShopFlow DZ** — SaaS B2B mobile-first pour les commerces qui vendent sur les réseaux sociaux.

## Technologies

React, Firebase, Tailwind CSS et Vercel.

## Lancer le projet

```bash
npm install
npm run dev
```

## Construire la version de production

```bash
npm run build
```
